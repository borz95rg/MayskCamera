MayskCamera — пакет шаблонов эффектов v1.0
============================================

Состав:
- effects.json — каталог эффектов, категории, названия, типы, параметры и пути к ресурсам.
- overlays/*.svg — векторные накладки: маски животных, короны, очки, украшения, макияж, рамки.
- backgrounds/*.svg — демонстрационные фоны для режима замены фона.
- filters — параметры цветовых пресетов в effects.json.
- beauty — список ползунков и начальные значения в effects.json.

Всего:
- 5 масок животных
- 8 3D/фантазийных эффектов
- 7 макияж/украшения
- 3 рамки/стикера
- 8 фонов
- 8 цветовых фильтров
- 7 параметров Face Beauty

ВАЖНО ДЛЯ РАЗРАБОТЧИКА
----------------------
Это пакет именно шаблонов и описаний, а не готовый движок распознавания лица.
SVG-накладки нужно привязывать к точкам лица (face landmarks), масштабировать и
поворотать по положению глаз/носа/лба. В effects.json для каждого шаблона есть
tracking.anchors и parameters.

Для реальной работы:
1. Face overlay / face makeup — нужен face landmark tracking.
2. Background — нужен person segmentation и замена заднего плана.
3. Фильтры — применяются как цветокоррекция кадра.
4. Beauty — ползунки подключаются к поддерживаемым функциям выбранного AR/beauty SDK.
5. Рамки — накладываются поверх финального кадра и при сохранении, и при видео.

SVG — исходные векторные шаблоны. Их можно перекрашивать, масштабировать и
рендерить в текстуру. Предпросмотр SVG не означает, что эффект уже отслеживает лицо.

Рекомендуемые категории интерфейса:
Все / Животные / Макияж / 3D-эффекты / Фильтры / Фон / Рамки и стикеры.

Формат каталога:
id — стабильный идентификатор эффекта;
name — подпись в приложении;
category — категория вкладки;
type — способ обработки;
asset — относительный путь к SVG;
tracking.anchors — ориентиры привязки к лицу;
parameters — стартовые параметры эффекта.

Пакет не содержит исходный проект приложения и не меняет его файлы.
