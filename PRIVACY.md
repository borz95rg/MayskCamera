# Политика конфиденциальности Maysk Camera

**Кратко:** Maysk Camera не собирает и не отправляет ваши фото, видео и личные данные.

- **Камера и микрофон** используются только для съёмки фото и видео по вашей команде.
- **Вся AI-обработка** (распознавание лиц и сцен, ретушь, фильтры, удаление объектов, улучшение звука) выполняется **на телефоне**. Изображения никуда не передаются.
- **Фото и видео** сохраняются только в памяти телефона (папка `DCIM/MayskCamera`).
- **Геолокация** (если вы включили «Геолокация» в настройках) записывается только в EXIF самого фото на телефоне.
- **Голосовое управление** использует системное распознавание речи Android только для команд «Снимок», «Запись», «Стоп».
- **Интернет** используется только для проверки и загрузки обновлений приложения с GitHub Releases. Передаются лишь стандартные данные HTTP-запроса (IP-адрес, версия приложения).
- **Отчёты о сбоях** не отправляются автоматически: приложение только предлагает поделиться текстом ошибки, и вы сами решаете, отправлять ли его.
- Приложение не содержит рекламы и трекеров.
