## 2. Что реально работает (по коду)
| Узел | Состояние |
|---|---|
| Камера | CameraX 1.4.1, свой `GlEffectProcessor` (OpenGL ES 2) как CameraEffect. Один GL-кадр идёт на экран, в MP4 и в снимок. Это правильная архитектура. |
| 3D-маски | 15 GLB, собственный рендер в том же GL-контексте, перекрытие лицом через «невидимую голову» в буфере глубины, поза по Face Mesh, One-Euro, удержание 450 мс. |
| Трекинг | ML Kit Face Detection каждый кадр + Face Mesh ~8 к/с (468 точек). Blendshapes нет, только рот/глаза по классификации. |
| Beauty (live) | Один параметр `uBeauty` в шейдере; отдельные ползунки есть только в статичном `ImageOps.skinSmooth` (по цвету кожи). |
| Фон | **Поправка к первой версии аудита.** Живая замена/размытие фона в GL уже подключены: маска человека ML Kit (~12 к/с) подаётся в шейдер (`uBgMask`) и работает в превью, видео и фото. Качество края (волосы, ореолы) на устройстве не проверено. |
| 2D-маски (Canvas) | 40+ PNG и Canvas-оверлеи. В MP4 не пишутся (подтверждено документами проекта). |

## 3. Почему маски выглядят «детскими» — корневые причины
1. **Сами модели.** Все 15 GLB генерируются скриптом `tools/ar_models/generate_models.py` из примитивов: конусы, торы, эллипсоиды. 650–3100 треугольников, цвет только по вершинам. Превью (previews/*.png) это видно: «уши» — конусы, корона — жёлтые конусы с шариками, голова — «яйцо». Никакой рендер этого не спасёт: нужны настоящие модели.
2. **Загрузчик GLB** (`GlbModel.kt`): только POSITION/NORMAL/COLOR_0 и baseColorFactor. Нет TEXCOORD, текстур, normal/ORM/emissive-карт, скиннинга, morph targets, glTF-анимаций.
3. **Шейдер** (`ArRenderer.kt`): один направленный свет, `diff*0.62+0.38` и грубый блик. Нет PBR, окружения (IBL), теней, AO, подповерхностного рассеяния, меха.
4. **Освещение не привязано к кадру.** Свет не оценивается по лицу, поэтому объект не «сидит» в сцене.
5. **Данные мимики бедные.** Нет 52 blendshapes и матрицы трансформации головы; поза считается по 6 точкам сетки.

## 4. Технологические решения
**Filament — не подключать.** У Filament свой EGL/SwapChain; картинка не попадает в поверхность, которую CameraX кодирует в MP4. Эта проблема уже была и привела к удалению Filament (AR3D_RU.md). Возврат к нему повторит риск. Альтернатива — расширить собственный рендер в `GlEffectProcessor`: текстуры, PBR-lite, IBL из заранее запечённой кубкарты, скиннинг на CPU/вершинном шейдере. Если потом понадобится полный glTF, Filament допустим только в варианте «рендер в SurfaceTexture/внеэкранный буфер и копия текстуры», и это надо сначала проверить экспериментом на устройстве.

**OpenGL ES 3.0.** Нужен для morph targets (texture buffer), instancing частиц, MRT. API 29 + ES 3.0 есть почти на всех устройствах; нужен fallback на ES 2.0 по `glGetString(GL_VERSION)`.

**MediaPipe Face Landmarker.** Даёт 478 точек, 52 blendshapes и матрицу позы, это главный апгрейд трекинга. Нужно проверить: артефакт `com.google.mediapipe:tasks-vision`, размер (+~15–25 МБ с моделью face_landmarker.task), режим LIVE_STREAM, лицензия Apache-2.0. Работает на отдельном потоке в `LiveAnalyzer`; ML Kit остаётся fallback. Версию и размер нужно сверить на актуальной документации перед подключением, из этой среды я это сделать не могу.

## 5. Главный блокер: ассеты
Код не создаст «реалистичные уши с шерстью» и «ювелирную корону». Нужны настоящие 3D-модели: PBR-материалы, UV, текстуры шерсти/металла, для лица — прокси-голова для occlusion. Источники: (а) 3D-художник под заказ, (б) готовые модели с явной лицензией, допускающей коммерческое встраивание (CC0/CC-BY, проверка каждой), (в) собственная работа в Blender. Генерация из кода через примитивы уже показала потолок качества. Это решение за вами: без реальных моделей остальная инженерия даст лишь более красивое освещение тех же конусов.

## 6. Что отсутствует полностью
- Реалистичный макияж по зонам (губы, веки, румяна, брови) с отдельными ползунками: нужна маска зон по 478 точкам в текстуре и шейдер.
- Уточнение края маски человека (волосы, ореолы): сама live-замена фона есть, края нужно проверить на устройстве.
- Запись 2D-масок и Compose-слоёв в MP4.
- Частицы, дым, бабочки с машущими крыльями, неон.
- Проверка на устройстве: знак зеркала фронталки, буфер глубины на разных GPU, лаг при быстрых поворотах.
