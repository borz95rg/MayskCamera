# Maysk Camera

Профессиональная камера для Android с искусственным интеллектом.
Kotlin · Jetpack Compose · CameraX 1.4 · OpenGL ES · ML Kit (вся AI-обработка на устройстве).

**Минимальная версия:** Android 10 (API 29). **Цель:** Android 15 (API 35).

---

## Как получить APK через GitHub Actions

1. Скопируйте **всё содержимое** этой папки в корень репозитория
   (рядом должны лежать `app/`, `gradle/`, `gradlew`, `settings.gradle.kts`, `.github/`).
2. **Один раз** добавьте ключ подписи в GitHub Secrets (см. ниже).
3. GitHub Desktop → Summary → **Commit to main** → **Push origin**.
4. Вкладка **Actions** → дождитесь зелёной галочки.
   Каждая сборка автоматически публикуется в **Releases** как `v1.0.N` с файлом `MayskCamera.apk`.

### Ключ подписи (один раз)
Без постоянного ключа каждая сборка подписана новым временным ключом, и обновление
не встанет поверх старой версии.

GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Name | Secret |
|---|---|
| `MAYSK_KEYSTORE_BASE64` | содержимое файла `MAYSK_KEYSTORE_BASE64.txt` |
| `MAYSK_KEYSTORE_PASSWORD` | содержимое файла `MAYSK_KEYSTORE_PASSWORD.txt` |

Файл `maysk-release.jks` и пароль храните в надёжном месте: с ними же публикуется приложение в Google Play.
**Не добавляйте их в репозиторий** (`.gitignore` уже это запрещает).

### Автообновление
- Приложение при запуске проверяет последний релиз на GitHub и предлагает «Обновить».
  Вручную: **Настройки → Проверить обновления**.
- Телефон может проверить обновления, только если репозиторий **публичный**
  (Settings → General → Danger Zone → Change visibility). Код при этом виден всем, а ключ подписи — нет, он в Secrets.
- Первый раз после перехода на постоянный ключ старую версию нужно **удалить вручную** — у неё был другой ключ.
- Android один раз спросит разрешение «Установка неизвестных приложений» для Maysk Camera.

Если сборка упала — скачайте логи (⋯ → Download log archive) и пришлите.

### Честно об ограничениях Android/CameraX
- **8K** — CameraX не даёт записывать 8K; режим пишет в максимальном доступном качестве (обычно 4K).
- **120/240 fps** — только если камера телефона отдаёт такие FPS сторонним приложениям; иначе «Замедленная» замедляет 60/30 fps ролик.
- **Выбор кодека H.265** — в CameraX 1.4 недоступен, кодек выбирает устройство.
- **RAW (DNG)** — вместо RAW есть опция «Сохранять оригиналы» (кадр без обработки, JPEG 100%).
- **AR-маски** — не входят в эту версию (нужна модель отслеживания лица в 3D).
- **Удаление объектов** работает на диффузионном заполнении — отлично для мелких объектов/дефектов, крупные объекты на сложном фоне могут оставлять размытое пятно.
- Аппаратные режимы производителя (Night/HDR/Bokeh/Auto) работают только на телефонах, которые их открывают через CameraX Extensions; иначе используется собственная обработка Maysk.

## Структура
```
app/src/main/java/com/maysk/camera/
  MainActivity.kt        навигация, разрешения, затвор громкостью
  CameraViewModel.kt     логика режимов, AI PRO, таймлапс, панорама, slow-mo, AI Audio
  camera/                CameraX контроллер, режимы, фильтры, голос, gl/ (шейдер реального времени)
  ai/                    ML Kit, анализ сцены, AI-улучшение, обработка изображений
  media/                 MediaStore, кодирование видео, AI Audio, склейка панорамы
  ui/                    тема, компоненты, экраны
```

## Подпись для Google Play
Создайте keystore, добавьте в Secrets репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
и замените `signingConfig` в `app/build.gradle.kts` на собственный.
